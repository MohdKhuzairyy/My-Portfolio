03 / About the Project

Project Overview

A brief introduction to the development of ParkMana.

ParkMana is a car parking management system developed to provide a more organised approach to parking space management. The system focuses on simplifying the process of managing parking slots, vehicle information and user parking activities.

The application includes separate interfaces for general users and administrators. Users can interact with the system through registration, login, parking slot selection, vehicle management, payment and parking history pages.

The administrative interface provides tools for managing parking slots, viewing registered user information and accessing system statistics.

The project provided practical experience in developing a web-based management system and understanding how different user roles interact with a database-driven application.
