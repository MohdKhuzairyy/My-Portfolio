# Harry Khuzairy — Personal IT Portfolio

A responsive, multi-page personal portfolio built with HTML, CSS and JavaScript.

## Pages
- `index.html` — Homepage
- `biodata.html` — Biodata, education, interests and timetable template
- `portfolio.html` — Selected projects
- `video.html` — Personal introduction video placeholder
- `comments.html` — Visitor feedback form
- `projects/parkmana.html` — ParkMana details
- `projects/landslide.html` — Landslide Management System details

## Before publishing
1. Add your professional photograph as `assets/images/profile.jpg`.
2. Fill the timetable in `biodata.html` with your actual current-semester schedule.
3. Add real project screenshots using the suggested filenames shown on the project pages.
4. Record your introduction video and save it as `assets/videos/intro.mp4`.
5. Create a Formspree form, then replace `YOUR_FORM_ID` in `comments.html` with your form ID.
6. Review the project technology lists and only keep items that were genuinely used or planned in the project.
7. Check all pages on desktop and mobile before submission.

## GitHub Pages deployment
1. Create a public GitHub repository, for example `harry-portfolio`.
2. Upload the contents of this folder to the repository root (the `index.html` file must be at the root).
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.

## Notes
- This is a static website and does not require XAMPP or a database.
- Formspree is an external service. The feedback form will not submit until its endpoint is configured.
- Do not upload passwords, private API keys or sensitive personal information to a public repository.
- The timetable and media assets are intentionally placeholders until your own materials are added.
